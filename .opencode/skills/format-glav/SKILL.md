# Формат глав проекта Marsel

## 🗂️ Структура проекта
| Папка | Назначение |
|-------|-----------|
| `0-Сырьё/` | Сырые материалы, идеи, наброски |
| `1-План/` | project.md, roadmap.md, TODO.md |
| `2-Черновик/` | Активные черновики глав (Глава_N.md, Черновик.md, Правки/) |
| `3-Рецензии/` | Ревью и рецензии |
| `4-Готово/` | Готовые главы (Глава_1.md ... Глава_N.md) |
| `5-Персонажи/` | Досье персонажей |
| `6-Лор/` | Механика магии, обучение, способности, правила мира |
| `7-Промпты/` | Промпты для агентов |
| `8-Материалы/` | Дополнительные материалы |
| `Шаблоны/` | Шаблоны (Досье.md) |

## 📖 Формат готовой главы (4-Готово)

Каждая глава — это Markdown-файл с чёткой структурой.

### Заголовок главы
```
## Глава [порядковая] / [Название]
```
Пример: `## Глава первая / Кровь зовёт`

### Хронологический штамп
Сразу после заголовка — время и место действия курсивом:
```
*[время]. [погода/атмосфера]. [локация].*
```
Пример: `*10:00. Утро после похорон. Пасмурно.*`

### Разделители сцен
Сцены разделяются `---` (три дефиса) на отдельной строке.

### Эпизоды
Крупные сцены внутри главы оформляются как подзаголовки:
```
### Эпизод [номер] / [Название]
```
Пример: `### Эпизод 1 / Утро`

После заголовка эпизода — снова время и место курсивом.

### Повествование
- **От первого лица** — рассказчик Марсель (я/мне/меня)
- Описания атмосферные, сенсорные (запахи, звуки, ощущения)
- Короткие предложения, рубленый ритм в напряжённых сценах

### Диалоги
Формат: `**Имя:** — реплика`
```markdown
**Бабушка:** — Солнце моё, вставай! Завтрак!
**Марсель:** — Доброе утро, ба.
**Лёва:** — братан, возьми трубку, как сможешь. всё ок?
```
- Имя персонажа **жирным**, затем двоеточие, пробел, тире, пробел, текст
- Если персонаж говорит эмоционально — допустимы (!, ?, —, ...)
- Мысли ГГ: в кавычках или в блоке цитаты `> "текст мысли"`

### Ритм и атмосфера
- Много коротких абзацев
- Сенсорные детали (запах нафталина, скрип пола, холодный пол)
- Внутренние монологи и рефлексия ГГ
- Контрасты (бытовое / сверхъестественное)

## 📝 Формат черновика (2-Черновик)

- Менее строгий, чем готовая глава
- Та же структура эпизодов и диалогов сохраняется
- Может содержать:
  - Комментарии и заметки (прямо в тексте)
  - TODO-списки
  - Альтернативные версии сцен
  - Ремарки для себя (например: «(добавить описание)»)
- Перед финалом черновик проходит через Ревьювера

## 👤 Формат персонажа (5-Персонажи)

### Frontmatter (YAML)
```yaml
---
type: character
name: Имя
role: "Краткое описание роли"
age: возраст
status: complete | draft
tags:
  - character
  - protagonist | side | antagonist
---
```

### Досье (человеческая форма)
```
## 👤 Досье:
- **Внешность**: описание
- **Характер / Манера речи**: описание
- **Что знает**: описание
- **Динамика с [кем-то]**: описание
```

### Досье (вампирская форма)
```
## 👤 Досье: (Вампир)
- **Внешность**: описание (изменения после обращения)
- **Способности**: описание
```

## 🌌 Формат лора (6-Лор)

- Markdown-заметки с иерархией заголовков (###, ####)
- Каждый файл — одна тема (механика_магии.md, обучения_Марселя.md и т.д.)
- Содержит:
  - Описание механик и правил
  - Историю мира
  - Взаимосвязи между элементами
  - Ограничения и условия

## 🎯 Пример оформления диалога
```markdown
**Даня:** — Ладно, мне пора. Ещё раз спасибо, Марс. Завтра встречаемся?
**Марсель:** — Завтра у меня планы. Скину в личку.
```

## 🎯 Пример эпизода
```markdown
### Эпизод / Тренировка

*18:00. Лес около особняка.*

Вечером отец забрал меня. Не в лес, а на задний двор особняка —
там была старая каменная площадка, заросшая мхом...
```

---

## ⚠️ Важно
- Не нарушай сложившийся формат глав при редактировании
- Все главы пишутся от первого лица (Марсель)
- Диалоги строго в формате `**Имя:** — реплика`
- Эпизоды нумеруются внутри главы
- При создании новой главы — следуй структуре готовых глав как образцу
