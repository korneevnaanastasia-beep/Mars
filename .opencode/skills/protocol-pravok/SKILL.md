# Skill: протокол-правок

## Описание
Пошаговый протокол для работы с файлами правок (`Правки_N_глава.md`, `Правки_сводная.md`).
Каждая пара «оригинал → замечание» обрабатывается отдельно с согласованием с пользователем.

## Когда использовать
- Пользователь просит применить правки из файла `*Правки*` к главе
- В задаче есть ссылка на файл правок и главу

## Протокол

### Шаг 1: Прочитай файл правок
- Открой файл правок
- В нём — пары строк:
  ```
  - ОРИГИНАЛЬНЫЙ ТЕКСТ (что было в главе)
      - ЗАМЕЧАНИЕ (что с этим делать)
  ```
- Каждая пара = одна правка, которую нужно применить

### Шаг 2: Покажи пользователю первую пару
- Выведи:
  ```
  Оригинал: «...»
  Замечание: «...»
  ```
- Предложи 2–4 варианта нового текста (ID: A, B, C, D)
- Дождись выбора

### Шаг 3: Запомни решение
- После выбора пользователя запиши его в заметку/память

### Шаг 4: Переходи к следующей паре
- Повторяй Шаги 2–3 для каждой пары из файла
- Если пар много — не торопись, обрабатывай по одной

### Шаг 5: После всех пар
- Собери все утверждённые решения
- Делегируй **Редактору** применение всех правок одной задачей (со списком замен)
- После применения — запусти **Ревьювера** (если менялась глава)

### Формат ответа пользователю
```
---
### Пара №N

**Оригинал:** «...»
**Замечание:** «...»

| ID | Вариант |
|----|---------|
| A | ... |
| B | ... |
| C | ... |
| D | Твой вариант |

Какой выбираешь?
```
