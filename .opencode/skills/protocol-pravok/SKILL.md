# Skill: протокол-правок

## Когда использовать
- **Любое изменение контента в книге**: главы, лор, персонажи, план, сюжет
- Пользователь дал файл правок (`Правки_N_глава.md`, `Правки_сводная.md`)
- Пользователь попросил написать новую главу/сцену
- Пользователь попросил исправить конкретное место
- Пользователь сказал «перепиши», «добавь», «убей», «измени»

НЕ использовать: косметические правки конфигов, промптов, вспомогательных файлов.

## Типы изменений

| Тип | Триггер | Источник |
|-----|---------|----------|
| 🛠️ Файл правок | «примени правки из файла», файл `*Правки*` | Файл `2-Черновик/Правки/` |
| 🆕 Новая глава | «напиши главу про...», «создай новую сцену» | Устный запрос + план |
| ✏️ Правка по запросу | «исправь вот это место», «перепиши диалог» | Устный запрос |
| 📚 Лор/Персонажи | «добавь способность», «обнови досье» | Устный запрос |

## Единый формат правки

Каждая правка — строка в таблице:

| Поле | Формат | Пример |
|------|--------|--------|
| **ID** | Сквозной номер | 1, 2, 3... |
| **Тип** | опечатка / стиль / лор / сюжет / формат / новая_глава | опечатка |
| **Файл** | Путь к файлу | 4-Готово/Глава_1.md |
| **Строки** | Номера строк (from-to) или «—» для нового текста | 23-24 |
| **Оригинал** | Что было (или «—» для нового текста) | «он встал и пошёл» |
| **Изменение** | Что будет | «он поднялся и направился» |
| **Статус** | pending / approved / applied / verified | pending |

## Протокол работы

### Шаг 1: Определи тип изменения
Определи, что хочет пользователь:
- Если есть файл правок → 🛠️ Файл правок
- Если просит новую главу/сцену → 🆕 Новая глава
- Если просит исправить конкретное место → ✏️ Правка по запросу
- Если просит изменить лор/персонажа → 📚 Лор/Персонажи

### Шаг 2: Сформируй список правок

**Для 🛠️ Файл правок:**
- Прочитай файл правок
- Каждая пара «оригинал → замечание» → одна строка в таблице
- Тип определи по контексту: опечатка/стиль/лор/сюжет/формат
- Файл и строки — пока неизвестны, заполни позже

**Для 🆕 Новая глава:**
- Сформируй план: название, эпизоды, ключевые сцены
- Это одна правка типа «новая_глава» с планом в поле «изменение»
- Файл: 2-Черновик/{НазваниеГлавы}.md

**Для ✏️ Правка по запросу:**
- Прочитай актуальную версию файла (через read)
- Найди конкретные строки
- Заполни «оригинал» и «изменение»

**Для 📚 Лор/Персонажи:**
- Прочитай текущую версию файла
- Определи что менять
- Заполни таблицу

### Шаг 3: Покажи пользователю таблицу правок

Выведи:
```
### Предлагаемые правки

| ID | Тип | Файл | Строки | Оригинал | Статус |
|----|-----|------|--------|----------|--------|
| 1 | опечатка | Глава_6.md | 45 | ... | pending |
| 2 | стиль | Глава_6.md | 89 | ... | pending |
| ... | ... | ... | ... | ... | ... |

Утверждаешь все или хочешь обсудить по одной?
```

Если правок <= 3 — можно показать каждую с деталями (оригинал + предлагаемое изменение).
Если правок > 3 — таблица + спросить «все сразу или по одной».

### Шаг 4: Получи подтверждение
Варианты ответа пользователя:
- **«Да» / «Утверждаю»** — одобрить все разом
- **«Давай по порядку»** — обсуждать каждую правку отдельно (как работал старый протокол)
- **«Правку N переделай»** — конкретная правка → предложи новые варианты (как A/B/C/D)

Для каждой правки, которую обсуждаешь отдельно, показывай:
```
**Оригинал:** «...»
**Изменение:** «...»
| ID | Вариант |
|----|---------|
| A | текущий вариант |
| B | альтернатива |
| C | твой вариант |

Какой выбираешь?
```

### Шаг 5: Обнови статусы
После утверждения — проставь: `approved`

### Шаг 6: Делегируй Редактору
- Передай Редактору задачу с таблицей утверждённых правок
- Для новой главы: план + структуру эпизодов
- Редактор применяет правки через `edit`

### Шаг 7: Верификация
После того как Редактор отчитался:
- Прочитай изменённые строки файла
- Сверь: совпадает ли результат с утверждённым изменением
- Если нет — отправь на доработку
- Если да — проставь статус `verified`

### Шаг 8: Сохрани в память
- Сохрани таблицу правок в agentmemory (`save`)
- Если был интересный паттерн — `lesson_save`
- После верификации изменений контента — запусти Ревьювера (если главы/лор/персонажи)

### Финальный отчёт

После завершения всех шагов — сформируй итоговую таблицу:

```
## Отчёт: {описание}
Всего правок: N

| ID | Тип | Файл | Строки | Статус |
|----|-----|------|--------|--------|
| 1 | опечатка | Глава_6.md | 45 | ✅ verified |
| 2 | стиль | Глава_6.md | 89 | ✅ verified |
| 3 | сюжет | Глава_6.md | 134 | ✅ verified |
```
