# Пакетное редактирование (batch-edit)

## Описание
Используй этот скилл, когда нужно внести множество правок в один файл разово, не редактируя каждую строку по отдельности.

## Когда применять
- Требуется заменить форматирование по всему файлу (например, все мысли `*текст*` на `> "текст"`).
- Нужно добавить атрибуции ко всем репликам определённого персонажа.
- Необходимо внести десятки типовых правок, которые проще выполнить одним обновлением файла.

## Алгоритм работы

1. **Чтение файла**: Прочитай целевой файл инструментом `read` (обязательно, иначе `write` не сработает).
2. **Анализ и план**: Составь список всех правок в формате:
   - Строка X: `старый текст` → `новый текст`
   - Или общие шаблоны замен.
3. **Формирование нового текста**: На основе прочитанного содержимого сформируй полный обновлённый текст файла со всеми правками.
4. **Запись**: Вызови инструмент `write` с полным новым текстом.
5. **Самопроверка**: Прочитай файл один раз (`read`), чтобы убедиться, что правки внесены верно.
6. **Коммит**: Выполни коммит через навык `git-commit`.

## Важные замечания
- **Не используй** инструмент `edit` для множественных правок. Этот скилл предполагает однократную запись через `write`.
- Если права нужно применить к нескольким файлам, обрабатывай их по очереди: прочитал один, записал, проверил, затем следующий.
- После каждого файла делай коммит.

## Пример

Задача: Исправить все мысли в Главе 3 на формат `> "текст"`.

1. `read` файла `Глава_3/Глава_3.md`.
2. В памяти заменить все `*мысль*` на `> "мысль"` и `_мысль_` на `> "мысль"`.
3. `write` обновлённого текста.
4. `read` для проверки.
5. `git-commit` с сообщением `fix(Глава_3): привёл мысли к формату > "текст"`.
