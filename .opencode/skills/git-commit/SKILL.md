# Инструкция по выполнению коммита
1. Выполни команду `git add .`, чтобы добавить все изменения.
2. Сгенерируй сообщение коммита на основе изменений (используй `git diff --staged` для просмотра добавленных изменений). **Сообщение коммита должно быть полностью на русском языке**, согласно правилам `AGENTS.md`.
3. Сохрани сообщение коммита в файл `/tmp/commit_msg.txt`.
4. Выполни команду `git commit -F /tmp/commit_msg.txt`.
5. Проверь вывод команды. Если коммит не создан (например, нечего коммитить), сообщи об этом пользователю.
6. Никогда не выполняй `git push` без явного запроса.
