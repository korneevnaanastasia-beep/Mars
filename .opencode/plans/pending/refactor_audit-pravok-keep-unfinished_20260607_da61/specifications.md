# Specifications

Проверка git-истории и файлов глав для определения какие правки уже применены

## Functional Requirements

- Проверить git log — найти коммиты с правками по каждой главе
- Сравнить каждую позицию из сводной таблицы с текущим состоянием файла главы
- Определить статус каждой правки: исправлено или не исправлено
- Сгенерировать обновлённую сводную таблицу только с неисправленными правками

## Non-Functional Requirements

- Правка считается исправленной, если она отражена в git commit И подтверждена в файле главы
- Если нет git-истории — проверять только по файлам глав напрямую
- Формат вывода — сводная таблица как в оригинале, но только неисправленные позиции

## Acceptance Criteria

- В файле Правки_сводная.md остаются только строки с неисправленными правками
- Исправленные правки удалены из таблиц по главам
- Сводные цифры пересчитаны

## Out of Scope

- Применение самих правок
- Редактирование глав
- Создание новых правок
