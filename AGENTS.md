## Learned User Preferences
- Все ответы, отчёты и документация — строго на русском языке
- Конфигурация opencode должна быть явной: плагины/скиллы/MCP прописаны в файлах агентов, а не только в opencode.json
- Для оформления всего, что не является мыслями, используются Obsidian callout типа `[!quote]`
- Мысли персонажей: `> *текст*` (Марсель) или `> *Имя: текст*` (другие), без слова «думает»
- В таблицах обязательно колонки: ID, Глава, Строка
- При git-операциях использовать `git add .`
- Compress и автокомпрессия включены глобально
- protocol-pravok — единственный протокол для любых изменений контента (главы, лор, персонажи, план). Pair-Review удалён. Исключение: быстрый трек для опечаток/формата (approve без протокола)
- Мафиози использует таблицу маршрутизации (9 категорий: новая глава, правки, лор/персонажи, проверка, оценка, идея, поиск, брифинг, статус) для выбора пайплайна. Без свободной рефлексии
- Поиск по проекту — через Скаута с ripgrep (rg), поиск в интернете — через Скаута с exa/deepwiki. glob/grep не используются
- Мафиози синхронизирует memory block project:project после каждого save(). Сабагенты передают факты для синхронизации
- Любое изменение контента через Мафиози: plan_create() → approve → task() → Редактор проверяет plan_read перед работой

## Learned Workspace Facts
- Двухуровневая архитектура opencode: глобальный (~/.config/opencode/) и проектный (Marsel/.opencode/)
- Проект Marsel — книга в жанре тёмное городское фэнтези, пишется в Obsidian
- Структура папок: 0-Сырьё, 1-План, 2-Черновик (Правки/), 3-Рецензии, 4-Готово, 5-Персонажи, 6-Лор, 7-Промпты, 8-Материалы, Шаблоны
- Проектные агенты (6): Мафиози (primary), Редактор (+plan_read), Скаут (rg+read, task:deny), Ревьювер (+task→Скаут), Идейник (+task→Скаут), Оценщик (+ask+task→Скаут)
- Проектные скиллы (6): batch-edit, continual-learning, format-glav, git-commit, intellisearch, protocol-pravok
- Главы от 1-го лица (Марсель). POV может переключаться. Формат: `## Глава`, штамп времени, `### Эпизод`, разделители `---`
- Диалоги: `**Имя:** — реплика`. Ремарки: `**Имя** ремарка: — речь`. Мысли: `> *текст*`. Не-мысли: `> [!quote]`
- protocol-pravok — универсальный шлюз: 4 типа правок (файл правок, новая глава, правка по запросу, лор/персонажи), 8 шагов, единый формат (ID/тип/файл/строки/статус), верификация после применения
- Оценщик — рецензия в стиле Энтони Юлай + premortem-анализ. Write:allow (только 3-Рецензии/), ask для прямых вопросов пользователю
- В opencode.json разрешены скиллы: intellisearch, protocol-pravok, evaluate-premortem
- format-glav содержит правила форматирования: callout, мысли, диалоги, структура глав
- Мафиози — 3-этапный протокол старта: Healthcheck (sessions + project:project) → Автоматический брифинг (profile + next + recall) → Обработка запроса по таблице маршрутизации
