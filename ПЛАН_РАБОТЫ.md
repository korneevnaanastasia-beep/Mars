# Пайплайн написания книги

> Не просто «что делать», а конвеер: что за чем, откуда берётся, куда кладётся.

---

## Как выглядит пайплайн

Это линия из 6 станций. Текст движется по ним последовательно — от первой к последней. На каждой станции с текстом что-то делают. На предыдущую не возвращаются.

```
  СЫРЬЁ         ПЛАН        ЧЕРНОВИК      ОБРАБОТКА      РЕЦЕНЗИЯ      ГОТОВО
 ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐    ┌────────┐    ┌────────┐
 │  идеи  │ → │  план  │ → │  текст │ → │  AI-   │ →  │ правка │ →  │ глава  │
 │  лор   │   │  сцены │   │  пишет │   │ чистка │    │  ты +  │    │ сдана  │
 │  вопросы│  │        │   │  автор │   │        │    │ AI     │    │        │
 └────────┘   └────────┘   └────────┘   └────────┘    └────────┘    └────────┘
                                                                          │
                                                                          ▼
                                                                   ┌────────┐
                                                                   │ Архив  │
                                                                   │ бэкап  │
                                                                   └────────┘
```

**Правило:** материал идёт только вперёд. Если на рецензии нашли косяк — правишь тут же и отправляешь дальше, а не переписываешь черновик с нуля.

---

## Станция 1: Сырьё

**Что здесь лежит:** всё сырое — идеи, мысли, вопросы, куски лора, ссылки.

**Папка:** `0-Сырьё/`

| Файл         | Что туда писать                |
| ------------ | ------------------------------ |
| `идеи.md`    | Любые сюжетные мысли           |
| `идеи_2.md`  | Мысли про мир, лор, вампиров   |
| `Вопросы.md` | Вопросы, на которые нет ответа |
| `лор.md`     | (новый) Справочник по миру     |

**Что делает автор:** сбрасывает мысли. Без системы, без порядка. Просто записать.

**Выход со станции:** список сырых идей, из которых можно собрать задачу.

---

## Станция 2: План

**Что здесь лежит:** задачи, планы сцен, структура.

**Папка:** `1-План/`

| Файл              | Что туда писать                  |
| ----------------- | -------------------------------- |
| `TODO.md`         | Задачи, разобранные из идей      |
| `план_главы_7.md` | (новый) План конкретной главы    |
| `шаблон_сцены.md` | (новый) 3-5 предложений на сцену |

**Что делает автор:**
1. Берёт сырьё из станции 1
2. Превращает в задачу в TODO.md
3. Берёт задачу — пишет план сцены
4. План сохраняет в `план_главы_N.md`

**Выход со станции:** план на 1 сцену (3-5 предложений) + задача в TODO.

---

## Станция 3: Черновик

**Что здесь лежит:** сырой текст, который только что написан.

**Папка:** `2-Черновик/`

| Файл | Что туда писать |
|------|-----------------|
| `Глава_7.md` | Сырой текст, только что написанный |
| `Черновик.md` | Мусорка для любых набросков |

**Формат файла:** без правил. Можно без заголовков, с ошибками, с пометками «тут дописать». Это черновик.

**Что делает автор:**

Пишет текст. Залпом. Не правит, не возвращается, не читает предыдущее.  
Цель — выдать текст. Качество — потом.

**Что делает AI (опционально):**

Если автор не хочет писать сам:
- Берёт `8-Промпты/Писательский.md` + план
- AI пишет черновик
- Автор проверяет и правит

**Выход со станции:** сырой текст (написанный автором или AI).

---

## Станция 4: Обработка

**Что здесь лежит:** тот же текст, но чистый и структурированный.

**Папка:** та же `2-Черновик/` — файл перезаписывается.

**Что делает AI:**

- Берёт `8-Промпты/prompt_structure.md` + сырой текст
- Приводит в порядок: расставляет заголовки, эпизоды, курсивы, разделители
- Структурирует внутренние монологи, диалоги

**Что делает автор:**

1. Проверяет, что AI ничего не сломал
2. Правит стилистику: убирает лишнее, переписывает корявые фразы
3. Приводит заголовки к единому формату:

```
## Глава N / Название

### Эпизод N / Название
```

4. Добавляет YAML-шапку:

```
---
title: Глава 7
status: draft
words: 0
pov: Марсель
tags:
  - chapter
---
```

**Выход со станции:** чистый, размеченный текст с едиными заголовками.

---

## Станция 5: Рецензия

**Что здесь лежит:** тот же текст + файл с замечаниями.

**Папки:** `2-Черновик/` + `3-Рецензии/`

| Файл          | Что туда              |
| ------------- | --------------------- |
| `Глава_7.md`  | Текст после обработки |
| `правки_7.md` | Замечания, разбор     |

**Что делает AI:**

- Берёт `8-Промпты/Энтони_Рецензер.md` + чистый текст главы
- Пишет разбор: что плохо, что хорошо, логические дыры
- Сохраняет результат в `3-Рецензии/правки_N.md`

**Что делает автор:**

1. Читает рецензию
2. Решает, с чем согласен
3. Вносит правки в текст главы
4. Стирает файл `правки_N.md` или ставит пометку «учтено»

**Выход со станции:** финальный текст главы (готовый к сдаче).

---

## Станция 6: Сдача

**Что здесь лежит:** готовая глава, готовая к сборке книги.

**Папка:** `4-Готово/`

| Файл         | Что туда         |
| ------------ | ---------------- |
| `Глава_7.md` | Финальная версия |
| `Глава_7.md` | Копия в Архив/   |

**Что делает автор — чеклист закрытия:**

- [ ] Поставить `status: done` в YAML главы
- [ ] Закрыть задачу в TODO.md
- [ ] Обновить досье (если появился новый персонаж)
- [ ] Сделать копию главы в `Архив/`
- [ ] Выдохнуть

**Выход со станции:** готовая глава, закрытая задача, порядок.

## Как выглядит час работы по пайплайну

```
09:00 — Открываешь TODO.md
      Берёшь задачу «написать сцену знакомства с Даней»

09:05 — Открываешь план_главы_7.md
      Записываешь 4 предложения плана

09:10 — Открываешь 2-Черновик/Глава_7.md
      Пишешь текст. Залпом. Без правок.

09:40 — Закрыл черновик. Идёшь пить чай.

09:50 — Скармливаешь текст AI с prompt_structure.md
      Получаешь чистый текст. Вставляешь обратно.

10:00 — Скармливаешь текст AI с Энтони_Рецензер.md
      Получаешь замечания. Правишь.

10:15 — Переносишь готовую главу в 4-Готово/
      Закрываешь задачу в TODO.md

10:20 — Всё. Глава готова.
```

## Правила пайплайна (жёсткие)

### 1. Только вперёд
Текст идёт от станции 1 к станции 6.  
Нельзя: писать главу 8, не закрыв главу 7.

### 2. Одна станция — одна папка
Каждая папка в проекте соответствует одной станции.  
Если файл лежит не в той папке — он не в пайплайне, его не существует.

### 3. Статус в YAML
У каждой главы в шапке — статус:

```yaml
status: draft     # черновик
status: review    # на рецензии
status: done      # готово
```

Дашборд читает статус из YAML, а не ищет слово «Конец» в тексте.

### 4. Порядок в TODO
В TODO.md есть 3 колонки:
- **Сделать** — что планируешь
- **В работе** — что делаешь прямо сейчас (не больше 1 задачи)
- **Готово** — что закончил (можно не хранить, просто галочка)

### 5. План перед текстом
Без плана в 3-5 предложений — не начинаешь писать.  
План хранится в `1-План/план_главы_N.md`.

### 6. Рецензия перед сдачей
Глава не переходит в `4-Готово/`, пока не прошла AI-рецензию.  
Даже если сам всё проверил — рецензия обязательна.

---

## Что даёт пайплайн

1. **Ничего не теряется** — каждая идея доходит до станции 6 или умирает на станции 1
2. **Нет каши в папках** — каждая папка для одного типа файлов
3. **Дашборд работает сам** — статус читается из YAML, не надо парсить текст
4. **Можно бросить и вернуться** — открыл TODO, увидел задачу, открыл папку, продолжил
5. **Не залипаешь на редактировании** — сначала напиши, потом правь
