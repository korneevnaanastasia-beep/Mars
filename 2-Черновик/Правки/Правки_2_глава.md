## Детализация ключевых правок

### П01 🔴 Хронология — Штамп времени не соответствует содержанию

**Текущий текст (строка 3):**
```
*10:00. Утро после похорон. Пасмурно.*
```

**Проблема:** Строки 5–23 описывают момент сразу после смерти бабушки (медики, тело уносят, захлопывается дверь) — это IMMEDIATELY после окончания Главы 1, когда похороны ещё НЕ были. Похороны происходят в Эпизоде 1 (строка 29). Штамп «после похорон» — ошибка.

**Дополнительно:** В строке 75 Марсель говорит Лёве «Похоронил уже. Два дня назад» — это означает, что похороны были 2 дня назад относительно момента диалога, но opening — это утро ДО похорон.

**Предлагаемое исправление:** Заменить штамп на `*10:00. Утро после смерти. Пасмурно.*` или `*День первый. 10:00. Пасмурно.*` — в зависимости от замысла автора.

### П02 🟡 Формат — Артефакты Obsidian в тексте

**Текущий текст (строка 46):**
```
Достаю телефон. Набираю. Гудки. Долгие. ^6eff59
```

**Текущий текст (строка 139):**
```
Это вообще не в кассу. ^идёт_откуда_куда ^84270a
```

**Текущий текст (строка 147):**
```
*23:30. Ночь. Каменноостровский, 60. Арка. Холодно, сыро.* ^идёт_откуда_куда2 ^ea937d
```

**Проблема:** `^`-блоки — технические якоря Obsidian. В финальный текст готовой главы не должны попадать.

**Предлагаемое исправление:** Удалить `^6eff59`, `^идёт_откуда_куда ^84270a`, `^идёт_откуда_куда2 ^ea937d`.

### П03 🟡 Формат — Пропущен пробел после `**Имя:**` перед `—`

**Пример (строка 58):**
```
**Марсель:**— Спасибо.
```
Должно быть:
```
**Марсель:** — Спасибо.
```

**Охват:** 15 строк (58–105 passim). При этом телефонный разговор (строки 48–56) отформатирован правильно — пробел есть. Ошибка систематическая, в одном блоке текста. Вероятно, артефакт копирования или смены формата при переносе.

**Предлагаемое исправление:** В 15 строках добавить пробел после `:**` перед `—`.

### П04 🟡 Формат — Нестандартное оформление мыслей

**Текущий формат (повсеместно, напр. строка 7):**
```
> "Не сейчас. Нужно держаться..."
```

**Стандарт (format-glav SKILL.md):**
```
> *Не сейчас. Нужно держаться…*
```

**Проблема:** 7 блоков мыслей (строки 7, 10, 34, 40, 44, 79, 159) используют `> "..."` вместо `> *...*`. Стандарт явно предписывает курсив внутри blockquote. Также строка 17: мысль `*ты сейчас так не вовремя…*` — курсив без blockquote.

**Предлагаемое исправление:** Унифицировать все мысли по стандарту: `> *текст*`. Строку 17 дополнительно обернуть в `>`.

### П05 🟢 Логика/Стиль — «Поздний вечер» в 18:00

**Текущий текст (строки 113, 115):**
```
*18:00. Вечер. Пасмурно, накрапывает дождь.*

Настал уже поздний вечер.
```

**Проблема:** 18:00 — это ранний вечер. «Поздний вечер» наступает ближе к 22:00–23:00. Небольшая, но заметная нестыковка.

**Предлагаемое исправление:** Убрать слово «поздний» или изменить штамп на более позднее время.
